# Customer Behaviour Analysis

Data analytics project showcasing customer behavior analysis using Python, SQL, and Power BI.

## Overview

This project analyzes customer behavior to uncover insights about purchasing patterns, revenue performance, review ratings, and shipping preferences. The dashboard and supporting analysis help identify trends across customer segments and product categories.

## Dashboard Highlights

- **74 Customers** analyzed
- **$59.64** average purchase amount
- **3.59** average review rating
- Subscription status breakdown
- Revenue and sales by category
- Revenue by age group
- Shipping type analysis

## Visuals Included

- KPI cards for key business metrics
- Subscription status donut chart
- Revenue by category bar chart
- Sales by category bar chart
- Revenue by age group chart
- Shipping type slicer
- Filters for gender, category, and subscription status

## Technologies Used

- **Python** for data analysis and preparation
- **SQL** for querying and transforming data
- **Power BI** for dashboard creation and visualization
